# 配对桌面版本验收

目标 Mac v0.2.1 / Windows v0.2.2；功能基线 desktop-4。Mac 已本机试用交付；Windows v0.2.2 已完成技术构建和本机安装／启动／卸载复验并发布 x64 安装包，但客户 GUI 体验与完整业务功能仍未验收。Mac 带头，Windows 跟随；操作系统对话框外观可不同，功能和计算输出必须一致。

| 场景 | 必须验证 |
| --- | --- |
| 安装启动 | 内置环境、无终端、中文／空格路径、只读资源、可视启动、错误与重试 |
| 生命周期 | 单实例、端口冲突、退出回收子进程、空闲无新增轮询 |
| 文件输入 | 系统多文件选择、拖拽、目录选择、取消不改值、逐表范围确认 |
| 核心业务 | 库存／销量／计划／出库／货损，缺失与0、单位、日期、重复与编码冲突 |
| 每日记录 | 新增、Excel导入、补空／替换、旧版、趋势、删除与恢复 |
| 原始价量与商品关联 | 双层日期、合并仓位、年份保留、0/空、原始来源、订货表关联、规格/地区冲突与别名持久保存 |
| 导入变更核对 | 新增/未变/冲突/补齐预览、旧新差异、策略与映射变化失效、显式更新保留旧版、重复不累计 |
| 日记录导出 | 当前筛选全部匹配记录跨页导出Excel/CSV，范围与销量口径明确、文字ID、原生保存重读一致 |
| 历史与导出 | 打开／重算边界、删除／恢复、Excel本机保存、同名备份和恢复、Excel／CSV下载 |
| 设置与迁移 | 模板、分析配置、日记录映射、主题跨端口与重启保留、ZIP导入导出及日志 |
| 原生下载 | XLSX／CSV Blob／ZIP选择路径，不自动覆盖已有文件 |
| 数据保护 | 应用升级不清历史，源文件／生成文件不随卸载删除 |
| 卸载 | 普通／彻底分类，确认、范围、可恢复；真实用户资料不用于破坏性测试 |
| 平台一致 | 配对版本功能清单相同、核心资源SHA一致，同一虚构样本逐项输出一致 |

每轮在测试空间记录真实通过、失败、未执行与环境限制，不能用静态代码检查替代系统原生操作测试。

## 历史基线与既有证据（2026-11-23，v0.1.9）

11月22日答疑已全部收齐。desktop-3已完成单品85%独立考核、总览逐款正差额合计、业务状态筛选与每日任务；缺失、零计划、月底到期和旧快照口径均有覆盖。净销量重建、货损双轨、源写回开关仍待实现，不列入本轮已交付。

Mac0.1.9新增原始价量表展开、持久商品关联、导入差异预览及筛选日记录导出。组合历史恢复后的所有原件及硬链接受普通导出保护，预览与提交均复查。221项Python回归、16项日记录UI、23项单品UI与16项外观测试通过；原生App实际系统保存Excel后重读4条日记录、2条关联及版本2一致，正常退出清理后端。证据在本机测试空间/原表接入验收。

现有真实价量样表有13个日期组，但169个价量组合均空，只验证结构；数值完整流程使用隔离虚构数据。不得将技术测试算作真实业务对账完成。

平台发布与共享代码按概览/GitHub分支与版本规定.md执行，GitHub对应docs目录。Windows原生包尚未完成，不把Mac通过的系统测试当成Windows已通过。

## 单品考核关键案例

- A计划100、完成200，B计划100、完成0：合计达成100%，A达标、B未达，缺口合计85，不能为0。
- 恰好85%计达标；有实际缺口时不能被浮点相对误差吞掉，包括大额计划差一分钱。
- 缺计划、缺完成和非正计划为待核对；已知缺口保留，完整任务不能冒充0。
- 截止日后剩余自然日均摊任务；月末仍未达标显示已到期，已达标任务真实0。
- 人工修正后重新分析生成新状态；旧快照保留历史数值和口径，新旧导出明确区分。


## v0.2 生命周期新增验收（2026-11-24）

以下是验收清单，不把源码已实现当成实机已通过。每个平台分别登记通过、失败、未执行及环境限制；Windows 外部报告与本机验证分列。

| 场景 | 必须验证 |
| --- | --- |
| 首次引导 | 品牌、版本、实际 Bundle 与数据路径、三步使用、默认只读和联网边界；打开目录真实有效 |
| GUI安装 | 目标目录可选/返回更改；默认、自定义、中文空格路径；权限/空间/非法路径失败；取消不复制 |
| 安装确认 | 实际来源/目标/版本明确；无同名覆盖、无链接绕过；复制和签名重读成功才启用 |
| 升级 | 从新版选择原目录；运行中旧版拒绝替换；确认后外部变化停止；旧包恢复副本保留；用户数据不改 |
| 完成页 | 立即启动/打开安装目录/完成分别生效；立即启动退出旧宿主并交接；无无提示后台安装进程 |
| 平台入口 | Windows快捷方式按选择创建并登记；Mac遵循Finder/App菜单习惯，无隐藏命令行要求 |
| 卸载选择 | 默认普通、两种单选真实互斥、取消无改动；确认页与方式一致；彻底卸载二次确认 |
| 卸载范围 | 明确白名单；原件、导入、生成、exports备份与未知文件保留；精确清理operations/state.json及writeback/settings.json、templates.json，保留writeback/backups和writeback/operations；不删父目录；实际Bundle路径；链接目录拒绝 |
| 卸载结果 | 实际移入废纸篓/回收站项目、遗留项、错误和恢复路径可见；部分失败不冒充成功 |
| 全链路启动 | backend-ready、page-loaded、frontend-ready依次记日志；总超时覆盖前端可操作；失败不无限等待 |
| 性能 | 固定设备/系统/构建/数据，首启/冷启/热启分别计时；全进程RSS或Working Set/Private Bytes，指标名明确 |
| 空闲/长静置 | 固定静置条件、CPU和资源曲线、退出后进程回收；磁盘未采集明确标空，不伪造0；先测后定阈值 |
| 移动盘下载 | 新文件安全发布；同目录私有stage复制、fsync及hash后排他原子发布，不覆盖已有文件/悬空链接；目标竞争清stage，最终名不暴露半文件；FS不支持排他rename则明确失败；真实FAT/exFAT另测 |

隔离文件系统测试位于测试空间/test_v02_desktop.py，覆盖自定义路径复制、升级旧包、签名失败保留、目标变化、运行中保护、清理白名单和同目录暂存及排他原子下载发布。此测试不代替真实安装、升级、废纸篓和Windows环境验收。性能采样脚本为desktop/measure_resources.py；40秒启动超时为错误保护，不是实测性能门槛。
