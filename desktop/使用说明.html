MAC 试用版 · v0.1.7

零售通使用说明

适用：Intel Mac，macOS 13 或以上。内置运行环境，使用时不需要安装 Python、Codex 或打开终端。当前安装包为本机试用版，尚未完成开发者签名公证；Apple Silicon 原生包与 Windows v0.1.8 由对应环境后续验证。

安装与启动

  1. 打开 零售通-v0.1.7-mac-Intel.dmg。
  2. 把“零售通”拖入窗口中的 Applications。复制进度由系统显示，完成后推出安装磁盘。
  3. 从“应用程序”打开“零售通”，等待启动进度完成。日常使用只需打开这个 App。

开始看盘

  1. 点击“导入数据”，选择或拖入 Excel；也可选择本机目录，勾选所需文件。
  2. 核对各工作表的用途、字段、仓库、单位与业务日期，不需要的表选择“忽略”。最多选择8份文件。
  3. 点击“预览导入范围”。格式变化由你确认；库存日期、重复计划或商品标识有冲突时，先调整再继续。
  4. 确认生成后，查看商品看盘、数据问题与来源。缺少的数据保留为空，不当作零。
  5. 点击“导出看盘表”，选择目录和文件名，预览后保存 Excel。同名覆盖会备份，可恢复。

单品目标考核

每款商品独立判断是否达到目标，默认门槛85%，完成额采用报单金额。总览的“逐款缺口合计”把各款未完成差额相加，超额商品不抵扣其他款。合计完成比例只作整体参考。

  • 点击“未达标”查看需要跟进的商品，逐款显示计划、考核目标、完成额、缺口及剩余每日任务。
  • 缺计划、缺完成数据或计划为零时标为“待核对”，完整任务不当作零；已知部分单独显示。
  • 每日任务按截止日之后至月末的剩余自然日计算。月底仍未达标会显示“本期已到期”。
  • 旧历史保持原口径和保存值。需要按新规则查看时，使用可用原件重新分析，生成新的历史记录。

每日价格与历史

  • “每日价格与销量”支持手工记录和 Excel 导入，按日期、商品、店铺保留售价及销量，可查看修订、删除和恢复。
  • “历史记录”保存每次分析，删除后可恢复；原文件变更或移动后，历史仍可查看与导出，重算须重新导入。
  • “本地数据与记录”可导出／导入迁移包，用于迁移旧启动版数据和备份。迁移包不包含用户源表和已生成文件。

数据、升级与退出

应用数据保存在 ~/Library/Application Support/零售通/，默认输出保存在 ~/Documents/零售通/生成文件/，也可选择其他目录。升级替换 App，保留这些用户目录。用“零售通 → 退出”结束运行，后台计算进程会一并停止。

用户原始 Excel 保持只读。退出前等待正在进行的分析或保存完成。库存与销量是否属于同一库存池，需要明确确认后才计算可售天数。

卸载

菜单“零售通 → 卸载零售通…”提供普通与彻底卸载，两种方式均先确认并移入废纸篓，可恢复。普通卸载仅移除 App；彻底卸载同时清理应用配置、历史、日志与缓存。用户源文件、导入文件副本及生成文件保留。请从已安装的 App 操作。

本版提供本地经营分析；线上定时采集、完整利润核算与复杂双层价量表自动适配继续后续开发。业务口径与真实原表对账仍需持续验证。Mac 奇数版本与 Windows 偶数版本按同一功能基线配对。
