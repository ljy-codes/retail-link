WINDOWS 试用版 · v0.1.10 · desktop-3

零售通使用说明

适用：Windows 10/11 x64。对应 Mac v0.1.9，复用同一业务代码与 desktop-3 功能基线。安装包内置 Python 运行环境，使用时不需要安装 Python、Codex 或打开终端。

安装前确认

  • 安装包文件名：零售通-v0.1.10-windows-x64-setup.exe。
  • 系统需要 Microsoft Edge WebView2 Runtime。Windows 10/11 通常已随 Edge 提供；若启动时提示缺失，请从 Microsoft 官方页面安装 Evergreen Runtime 后重新启动。
  • 本版尚未代码签名，Windows SmartScreen 可能显示“Windows 已保护你的电脑”。请先核对文件来源和下方 SHA-256；确认无误后可选择“更多信息 → 仍要运行”。
  • 程序按当前用户安装，不要求管理员权限。

安装与启动

  1. 双击安装程序，等待安装完成。
  2. 从开始菜单打开“零售通”。日常使用只需打开这个应用。
  3. 首次启动会准备本地工作空间。若页面提示失败，可先点击“重新启动”；仍失败时检查 WebView2 Runtime 是否可用。

程序目录：%LOCALAPPDATA%\Programs\零售通\；应用数据：%LOCALAPPDATA%\零售通\；默认生成目录：%USERPROFILE%\Documents\零售通\生成文件\。也可在保存对话框中选择其他目录。

开始看盘

  1. 点击“导入数据”，选择 Excel；也可选择本机目录，勾选所需文件。
  2. 核对各工作表的用途、字段、仓库、单位与业务日期，不需要的表选择“忽略”。最多选择 8 份文件。
  3. 点击“预览导入范围”。格式变化由你确认；库存日期、重复计划或商品标识有冲突时，先调整再继续。
  4. 确认生成后，查看商品看盘、数据问题与来源。缺少的数据保留为空，不当作零。
  5. 点击“导出看盘表”，选择目录和文件名，预览后保存 Excel。同名覆盖会备份，可恢复。

当前安装包未附带示例工作簿。首页会明确提示“安装包未附带样例，请选择 Excel 文件”，不会发送必然失败的样例请求。

单品目标考核

每款商品独立判断是否达到目标，默认门槛 85%，完成额采用报单金额。总览的“逐款缺口合计”把各款未完成差额相加，超额商品不抵扣其他款；合计完成比例只作整体参考。

  • 点击“未达标”查看需要跟进的商品，逐款显示计划、考核目标、完成额、缺口及剩余每日任务。
  • 缺计划、缺完成数据或计划为零时标为“待核对”，完整任务留空，已知部分单独显示。
  • 每日任务按截止日之后至月末的剩余自然日计算；月底仍未达标会显示“本期已到期”。
  • 旧历史保持原口径和保存值。需要按新规则查看时，使用可用原件重新分析，生成新的历史记录。

每日价格与历史

  • “每日价格与销量”支持手工记录和 Excel 导入，按日期、商品、店铺保留售价及销量，可查看修订、删除和恢复。
  • “历史记录”保存每次分析，删除后可恢复；原文件变更或移动后，历史仍可查看与导出，重算须重新导入。
  • “本地数据与记录”可导出／导入迁移包，用于迁移旧数据和备份。迁移包不包含用户源表和已生成文件。

原始价量表与商品关联

  1. 打开“每日价格与销量 → 商品关联”，可导入订货资料表，预览来源商品 ID、规格和仓位，确认后保存。不同商品不会仅因名称相同而合并。
  2. 需要关联不同来源时，可手动填写来源商品 ID、来源仓位、标准商品标识和标准仓位。关联只作用于后续导入，旧日记录保留保存时的商品和数值。
  3. 在“导入价格表”中选择双层日期表，检查日期组、售价与销量列以及合并仓位。系统保留表内完整年月日，不按文件名改年份。
  4. 预览新增、未变、冲突及可补齐记录，查看旧新差异。默认保留已有记录，选择补齐或更新时先重新预览；更新保留旧版本。同日同商品同仓位不累计重复行。
  5. 价量都为空的日期组跳过，真实 0 保留。只有表头和商品、没有价量数值的空模板不会产生日记录。
  6. 在“日记录”中按日期、商品和仓位筛选，导出 Excel 或 CSV。导出包含全部匹配记录及范围说明，不只当前页；Excel 另含当前商品关联。保存使用 Windows 系统对话框。

每日记录中的销量沿用来源的当日销量，尚未自动扣除售后，也不自动与看盘中的 Excel 销量相加。净销量重建、货损双轨和源文件写回仍按后续阶段分批实现。

数据、升级与退出

应用数据、商品关联、历史、偏好和 WebView2 用户数据保存在 %LOCALAPPDATA%\零售通\。用户选择的原始资料位于其“原始资料”子目录；生成文件默认位于 Documents。升级覆盖安装会替换程序目录并保留应用数据。

用户原始 Excel 默认只读。退出前等待正在进行的分析或保存完成。库存与销量是否属于同一库存池，需要明确确认后才计算可售天数。

卸载

  • 从 Windows“设置 → 应用 → 已安装的应用”选择“零售通”卸载，或从卸载信息中选择普通／彻底方式。
  • 普通卸载：删除程序、开始菜单快捷方式和卸载登记，保留应用数据、历史、设置与原始资料。
  • 彻底卸载：额外清理应用数据和缓存，但始终保留“原始资料”“导入文件”“生成文件”及 Documents 中的用户文件。
  • 删除内容尽量移入回收站，便于误操作恢复。用户源文件和生成文件不会因卸载被主动删除。
