## 目录约定

- `概览/`：四份规划、过程、答疑与总结文档。
- `原始资料/`：用户提供的原件；页面上传的原件进入其“导入记录”子目录。
- `开发空间/`：程序、配置、启动脚本、开发说明和构建脚本。
- `本地数据/`：持久历史、日记录及删除恢复数据；独立于工具版本。
- `测试空间/`：自测代码、样本、报告、测试运行数据和截图。
- `产品交付/`：仅最新可运行版本及必要启动／使用文件，不含自测和旧版本。

## 当前实现规则

- 缺失与 0 分开；未经明确对齐，不修改 Excel 年份。
- 库存池未确认前不计算可售天数；在途不计入现货。
- 85% 门槛、统计日期、计划口径、金额模式可配置；默认项属于探索设定，不替代业务确认。
- 手动修正可还原，原件不改写；其他文件不自动继承当前文件的人工调整。
- 目录读取当前为扫描后选择分析，不宣称已具备目录监控或 URL 抓取。
