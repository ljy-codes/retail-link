### 验证范围

- 安装程序生成并执行载荷完整性检查；内置 Python、`server.py`、`backend/`、`web/`、卸载脚本存在。
- 打包后端冒烟通过：`/api/health`、`/api/import/templates`、缺少样例时 `/api/sample` 返回明确 400、未知 API 返回 JSON 404。
- 真实安装后 WebView2 页面渲染，版本显示 v0.1.10；首页不显示必然失败的样例按钮，并显示“安装包未附带样例，请选择 Excel 文件”。
- 单实例再次启动会激活已有窗口；退出后无残留 `runtime\python.exe`、ready 文件清理、本地端口关闭。
- 原生文件／目录选择、取消不改变当前值、Excel/CSV 另存实际落盘并重读。
- 外观偏好修改后重启保持；覆盖升级保留应用数据、历史与偏好。
- 普通卸载退出码 0，删除程序、快捷方式和 HKCU 卸载项并保留应用数据；彻底卸载退出码 0，删除数据库、偏好、日志和 WebView2 数据，但保留原始资料、导入文件、生成文件和 Documents 用户文件。
- 卸载脚本采用 UTF-8 BOM 并移除 Windows PowerShell 5.1 会误判的中文弯引号；安装目录中的脚本已用 `powershell.exe` 5.1 实际解析，退出码 0。
- Python 全量回归：171 项通过，2 项环境跳过（现成 Mac App 与当前 Windows 账号无创建符号链接权限）；Windows 包契约 8 项通过。
- Node 界面脚本：日记录 16/16、单品考核 23/23，共 39/39 通过；新增 JavaScript 语法检查通过。

### 已知限制

- 安装包未代码签名，SmartScreen 可能提示风险；发布时必须核对 SHA-256 与来源。
- Windows 10/11 需要 Microsoft Edge WebView2 Runtime；通常随 Edge 提供。
- 仅提供 x64 试用包，未提供 arm64 原生包。
- 真实价量样表只有结构、价量数值为空；本轮用虚构工作簿完成技术闭环，不等同于真实业务对账。
- 净销量重建、货损双轨和受控源文件写回仍属后续阶段。
- 自动化测试不能替代全部真实客户环境、复杂 Excel 格式和业务口径验收。

### 交付约束

本地 `产品交付/` 和 GitHub Release 均只保留安装包与 HTML 两个资产。源码仓库不提交应用二进制、构建缓存、运行数据、业务原表或测试虚构数据。
