本版补齐desktop-4协议适配：`frontendReady`不再要求`id`，启动总保护覆盖到页面可操作；启动页显示“运行环境 → 后端就绪 → 页面加载 → 可操作”及耗时，并提供启动诊断入口。Windows安装器改为正式页面，可浏览和修改安装位置，支持中文、空格和自定义盘符路径，安装前检查可写权限与空间；立即启动、桌面快捷方式和开始菜单快捷方式分别按勾选执行，完成页显示实际路径、产品简介、首次使用、本地数据和联网说明。卸载器从HKCU `InstallLocation`定位实际目录，提供默认选中的普通卸载和需二次确认的彻底卸载，结果页列出已删除、已保留、失败项和日志位置，失败返回非零。

### 技术验收范围

- Windows包装专项18项通过；Python全量回归274项通过、7项环境跳过。
- 最终包静默安装到`D:\Program Files\零售通`，退出码0；HKCU登记路径、版本0.2.2、桌面和开始菜单快捷方式均核对一致。
- 最终包实际启动：后端约2.00秒就绪，约2.43秒收到`frontendReady`并进入可操作；`/api/health`返回`version=0.2.2`、`platform=windows`、`featureLevel=desktop-4`。
- 第二次启动退出码0，首个实例继续运行；正常关闭后应用进程、内置Python、本地监听端口和ready文件均回收。
- 普通卸载退出码0，程序目录、快捷方式和HKCU登记删除；卸载前已有197个应用数据及Documents文件逐一比对SHA-256，0缺失、0改写，新增卸载记录文件符合预期。
- 彻底卸载已实测退出码0，清理日志、历史、WebView2和指定应用配置；原始资料、exports、写回备份、恢复记录及Documents用户文件按5个哨兵核对全部保留。
- 本次空闲完整进程树实测9个进程，Working Set合计约649.9 MB、Private合计约314.4 MB。该结果用于记录用户反馈，不代表设置或达到性能通过阈值。

### 验收结论与已知限制

- 结论：Windows技术构建、安装、启动、单实例、资源回收和两种卸载范围通过；客户GUI安装／卸载体验复验、完整业务功能验收仍未完成。
- 用户现场反馈的“安装器太low、没有启动／快捷方式选择、缺少产品介绍、启动慢、启动后内存高、卸载不可选且无结果回音”已进入`人工验收bug.md`，不能因本版技术通过而关闭。
- 安装包未代码签名，SmartScreen可能提示；Windows 10/11需要Microsoft Edge WebView2 Runtime；仅提供x64试用包。
- 启动性能目前只有一次热启动和一次静置样本，尚未完成首次、冷启动、热启动及长时间静置的统一基线矩阵。

### 验证范围

- 安装程序生成并执行载荷完整性检查；内置 Python、`server.py`、`backend/`、`web/`、卸载脚本存在。
- 打包后端冒烟通过：`/api/health`、`/api/import/templates`、缺少样例时 `/api/sample` 返回明确 400、未知 API 返回 JSON 404。
- 真实安装后 WebView2 页面渲染，版本显示 v0.1.10；首页不显示必然失败的样例按钮，并显示“安装包未附带样例，请选择 Excel 文件”。
- 单实例再次启动会激活已有窗口；退出后无残留 `runtime\python.exe`、ready 文件清理、本地端口关闭。
- 原生文件／目录选择、取消不改变当前值、Excel/CSV 另存实际落盘并重读。
- 外观偏好修改后重启保持；覆盖升级保留应用数据、历史与偏好。
- 普通卸载退出码 0，删除程序、快捷方式和 HKCU 卸载项并保留应用数据；彻底卸载退出码 0，删除数据库、偏好、日志和 WebView2 数据，但保留原始资料、导入文件、生成文件和 Documents 用户文件。
- 卸载脚本采用 UTF-8 BOM 并移除 Windows PowerShell 5.1 会误判的中文弯引号；安装目录中的脚本已用 `powershell.exe` 5.1 实际解析，退出码 0。
- Python 全量回归：171 项通过，2 项环境跳过（现成 Mac App 与当前 Windows 账号无创建符号链接权限）；Windows 包契约 8 项通过。
- Node 界面脚本：日记录 16/16、单品考核 23/23，共 39/39 通过；新增 JavaScript 语法检查通过。

### 已知限制

- 安装包未代码签名，SmartScreen 可能提示风险；发布时必须核对 SHA-256 与来源。
- Windows 10/11 需要 Microsoft Edge WebView2 Runtime；通常随 Edge 提供。
- 仅提供 x64 试用包，未提供 arm64 原生包。
- 真实价量样表只有结构、价量数值为空；本轮用虚构工作簿完成技术闭环，不等同于真实业务对账。
- 净销量重建、货损双轨和受控源文件写回仍属后续阶段。
- 自动化测试不能替代全部真实客户环境、复杂 Excel 格式和业务口径验收。
