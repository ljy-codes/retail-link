MAC 试用版 · v0.2.1

零售通使用说明

适用：Intel Mac，macOS 13 或以上。内置运行环境，使用时不需要安装 Python、Codex 或打开终端。当前安装包为本机试用版，尚未完成开发者签名公证；Apple Silicon 原生包与 Windows 目标 v0.2.2 由对应环境后续验证。

安装与启动

  1. 打开 零售通-v0.2.1-mac-Intel.dmg。可将 App 拖到 Applications 或自己选择的可写目录。
  2. 也可打开 App，在菜单“零售通 → 安装与升级…”图形选择目录，核对实际来源、版本与目标。复制及完整性校验完成后，显示“立即启动”“打开安装目录”和“完成”。
  3. 首次引导列出用途、三步操作、实际应用位置及本地数据位置。启动中显示当前阶段与耗时；失败可重新启动，菜单“显示启动诊断”定位记录。

开始看盘

  1. 点击“导入数据”，选择或拖入 Excel；也可选择本机目录，勾选所需文件。
  2. 核对各工作表的用途、字段、仓库、单位与业务日期，不需要的表选择“忽略”。最多选择8份文件。
  3. 点击“预览导入范围”。格式变化由你确认；库存日期、重复计划或商品标识有冲突时，先调整再继续。
  4. 确认生成后，查看商品看盘、数据问题与来源。缺少的数据保留为空，不当作零。
  5. 点击“导出看盘表”，选择目录和文件名，预览后保存 Excel。同名覆盖会备份，可恢复。

单品目标考核

每款商品独立判断是否达到目标，默认门槛85%，完成额采用报单金额。总览的“逐款缺口合计”把各款未完成差额相加，超额商品不抵扣其他款。合计完成比例只作整体参考。

  • 点击“未达标”查看需要跟进的商品，逐款显示计划、考核目标、完成额、缺口及剩余每日任务。
  • 缺计划、缺完成数据或计划为零时标为“待核对”，完整任务不当作零；已知部分单独显示。
  • 每日任务按截止日之后至月末的剩余自然日计算。月底仍未达标会显示“本期已到期”。
  • 旧历史保持原口径和保存值。需要按新规则查看时，使用可用原件重新分析，生成新的历史记录。

每日价格与历史

  • “每日价格与销量”支持手工记录和 Excel 导入，按日期、商品、店铺保留售价及销量，可查看修订、删除和恢复。
  • “历史记录”保存每次分析，删除后可恢复；原文件变更或移动后，历史仍可查看与导出，重算须重新导入。
  • “本地数据与记录”可导出／导入迁移包，用于迁移旧启动版数据和备份。迁移包不包含用户源表和已生成文件。

原始价量表与商品关联

  1. 打开“每日价格与销量 → 商品关联”，可导入订货资料表，预览来源商品ID、规格和仓位，确认后保存。不同商品不会仅因名称相同而合并。
  2. 需要关联不同来源时，可手动填写来源商品ID、来源仓位、标准商品标识和标准仓位。关联只作用于后续导入，旧日记录保留保存时的商品和数值。
  3. 在“导入价格表”中选择双层日期表，检查日期组、售价与销量列，以及合并仓位。系统保留表内完整年月日，不按文件名改年份。
  4. 预览新增、未变、冲突及可补齐记录，查看旧新差异。默认保留已有记录，选择补齐或更新时先重新预览；更新保留旧版本。同日同商品同仓位不累计重复行。
  5. 价量都为空的日期组跳过，真实0保留。只有表头和商品、没有价量数值的空模板不会产生日记录，补齐数值后可重新导入。
  6. 在“日记录”中按日期、商品和仓位筛选，导出Excel或CSV。导出包含全部匹配记录及范围说明，不只当前页；Excel另含当前商品关联。保存使用系统对话框。

每日记录中的销量沿用来源的当日销量，尚未自动扣除售后，也不自动与看盘中的Excel销量相加。每项指标以界面显示的口径和待核对状态为准；缺少真实发货、售后或盘点资料时，不能把结构适配当作真实业务对账完成。

经营核对与分仓

  1. “商品关联”支持来源系统、商品ID、SKU/规格和仓库ID。主看盘与日记录共用对照；同ID多规格或同名不同仓不会自动混在一起。修改关联不改写旧历史。
  2. 点击商品查看分仓现货；合计仅作辅助。仓库没有同库存池的完整销量时，可售天数保留未计算。
  3. 打开“经营核对 → 导入与差异”，选择货款、仓库销量、售后汇总或发货/售后事件。自动识别不足时调整工作表和字段，核对预览后保存。重复内容不累计，更新保留旧版。
  4. 在“净销量双视角”选择期间和观察截止日。原销售归属与售后发生分别显示，不相加。缺事件ID、单位、关联或完整覆盖依据时只显示已观察值，完整结果保留待核对。来源汇总不能代替事件明细。
  5. “货损双轨”按同商品、同仓和同期间输入期初、入库、出库、实盘及登记值，查看公式盘差和差异。缺数据不填0，盘差不自动认定为货损；人工确认差异须填写说明。
  6. 导出经营核对Excel包含所选期间结果、来源、事件、扣减、盘差及待核对项；与看盘原有的映射销量分别列示。

受控源文件写回

  1. 进入“经营核对 → 受控源写回”，了解影响并开启开关；默认仍是新建结果文件。
  2. 选择实际原件路径，确认工作表、商品键和一个允许修正的数值字段。同ID多规格可增加规格键；目标必须能唯一定位。
  3. 输入修正值，预览文件、工作表、单元格、商品和旧新值。勾选本次确认后写回，系统先备份，再生成副本并重读验证。
  4. 写回记录提供恢复范围和再次确认；原件或备份已被外部修改会拒绝覆盖。备份及恢复记录只保存在本机，不进入迁移包，迁入后写回默认关闭。

首期限定简单.xlsx模板。宏、图片/图表、外部链接、扩展数据验证、公式目标及带计算缓存的公式工作簿不能写回，以免丢失内容或沿用过期结果；请另存结果。不能通过普通导出覆盖原件。CSV可能被Excel重新解析ID，需二次编辑时优先使用Excel导出。

数据、升级与退出

应用数据保存在 ~/Library/Application Support/零售通/，默认输出保存在 ~/Documents/零售通/生成文件/，也可选择其他目录。升级时先退出旧 App，从新版 DMG 打开“安装与升级…”，选择原 App 所在目录。旧版保留为同目录“零售通-升级前-…”恢复副本，应用数据保持原位；需要恢复时先退出新版，再使用旧包。商品关联与日记录一起进入迁移包。用“零售通 → 退出”结束运行，后台计算进程会一并停止。

用户原始 Excel 默认只读。开启受控源写回时，每次仍须预览并确认具体差异。退出前等待正在进行的分析或保存完成。库存与销量是否属于同一库存池，需要明确确认后才计算可售天数。

卸载

菜单“零售通 → 卸载零售通…”明确选择普通或彻底卸载，默认普通；下一步显示本次实际清理路径，再确认。普通只移走当前 App，彻底另清理白名单中的配置、历史、日志和缓存。原件、导入副本、生成文件、文件备份及未知文件始终保留。彻底卸载只清理经营账本状态与写回设置、模板；写回原件备份和恢复记录保留，其父目录不会整体删除。成功或部分失败都会显示结果与废纸篓恢复位置，结果记录保存在 Documents/零售通/卸载记录。请从已安装的 App 操作，磁盘映像只需推出。

本机与联网

工作簿在本机处理，本地服务只监听本机地址；当前不自动上传业务文件，也不定时抓取线上数据。主动点击外部链接时使用系统浏览器。启动日志只用于本地诊断，可从菜单查看。

本版采用客户指定的红色折线图标，并支持原始价量表、分仓库存和经营核对。线上定时采集、完整利润核算与其他复杂格式继续分阶段开发，真实业务结果仍需与人工经营表对账。Mac 奇数版本与 Windows 偶数版本按同一功能基线配对。
