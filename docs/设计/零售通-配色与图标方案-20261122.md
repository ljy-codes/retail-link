# 零售通 · 最新配色与软件图标方案

> 依据：`配色知识库.md`（2026-11-22，554 套配色 / 161 个传统色 / 348 组 Sanzo Wada）与 `配色对比.html`。  
> 适用：零售通 v0.1.x 原型 → v0.2 真实业务适配；桌面端、Web 端、PWA 共用一套 token。  
> 结论：零售通是**数据密集型 B 端工具**，不是内容/创作/AI 产品。主方案选 **墨蓝 · 青绿**，只保留一套品牌色 + 浅/深两套明暗；经典紫降级为图表辅助色，不再做整页主题。

---

## 1. 为什么选“墨蓝 · 青绿”

知识库的三条硬规则：

1. 正文对比度 ≥ 4.5:1，控件/图标 ≥ 3:1；
2. 1 个主色 + 1 个强调色 + 一组中性色，最多再加 2–4 个语义色；
3. 底色 60–70%，文字/主体 20–30%，强调色 5–10%。

零售通的场景是“每天看库存、销量、计划、货损”，需要：

- **可信**：深蓝/墨蓝，适合长期、专业、B 端；
- **效率**：青绿只做数据、增长、周转、完成；
- **克制**：大面积中性色，数字和表格是主角；
- **可读**：8 小时盯表，不能用高饱和粉紫/荧光绿做大面积。

所以不选：

- 粉紫/莫兰迪/国风高饱和四色：适合封面、内容、女性/生活类，不适合数据表；
- 亮蓝 `#2F6BFF` 做大按钮：白字对比度只有 4.5:1，刚好压线；
- 青绿 `#0D9488` 做大按钮：白字只有 3.74:1，不达 AA；
- 多套整页主题：看盘表在客户演示时不一致，紫色大面积也会抢读数。

### 2.8 60-30-10 用法

- **60–70%**：`--bg` / `--surface` / `--surface-2`，大面积中性；
- **20–30%**：文字、表格、数字、图标；
- **5–10%**：墨蓝主按钮、青绿趋势、状态点；
- 语义色只用于状态，不做装饰背景。

## 5. 软件图标建议

### 5.1 推荐方向：货箱 + 上升柱

**一句话：** 一个深墨蓝 squircle，里面是白色货箱轮廓，箱内三根青绿上升柱，最高柱上方一个白色数据点。

- **识别**：货箱 = 库存/零售；上升柱 = 销量/周转/增长；数据点 = 看盘。
- **小尺寸**：16px 时保留“箱体 + 三根柱”，去掉渐变、阴影、细小高光。
- **颜色**：底 `#0B1F3A`，主体 `#E6F7F3`，数据 `#0F766E → #2DD4BF`，高光 `#FFFFFF`。
- **比例**：底 60–70%，箱体/柱 25–35%，白点 5–10%。
- **风格**：扁平/微立体，不做拟物 3D，不做玻璃。
- **不要**：文字“零售通”、Excel 网格、购物车、金币、彩虹渐变、超过 3 个色相、细线。

### 5.2 备选方向：货箱 + 增长箭头

- 箱体轮廓 + 一条从箱内穿出的青绿→亮蓝上升箭头；
- 更适合“调整报单/活动节奏、向上增长”的叙事；
- 16px 时箭头要加粗、去掉箭头尖的细节，否则会糊。

### 5.3 备选方向：R 字标

- 粗几何 R，右腿延伸为上升箭头；
- 适合品牌期/官网/发布会，不适合作为第一版唯一图标；
- 16px 下文字形容易糊，必须做简化字标。

### 5.4 图标色板

| 角色 | 浅色/通用 | 深色/小尺寸 |
| --- | --- | --- |
| 底 | `#0B1F3A` | `#071426` |
| 主体/箱体 | `#E6F7F3` | `#E6F7F3` |
| 数据/柱 | `#0F766E` → `#2DD4BF` | `#2DD4BF` |
| 高光/点 | `#FFFFFF` | `#FFFFFF` |
| 可选辅助 | `#1F4E79` | `#6BA6D9` |

### 5.5 尺寸与导出

- 主画布：`1024×1024`；macOS squircle 内容区约 `824×824`，圆角约 `185px`，四周留白约 `100px`；
- iOS：`1024×1024`，不预裁圆角、不透明；
- Android：`108×108dp` 自适应，前景/背景两层，72dp 安全区；
- Windows：`256×256`，另出 16/24/32/48/64/128；
- Web favicon：16/32/48；
- PWA：192/512，maskable 留 10% 安全边；
- 菜单栏/托盘：单色模板图标，透明底，`#16202A`（浅）/ `#E6EDF7`（深）。

### 5.6 小尺寸验收

- 缩到 16px / 32px，离屏幕 1 米仍能看出“箱 + 柱”；
- 转灰度，轮廓仍清楚；
- 放浅色/深色背景都不消失；
- 和同系列图标并排，圆角、线宽、色温一致；
- 不用文字也能认出是“零售数据工具”，不是“购物 App”或“Excel 插件”。

## 9. 2026-11-26 用户提出的桌面工作台风格参考

用户提供了一张桌面数据工作台截图，作为零售通后续桌面界面的视觉参考。该截图只用于记录风格方向，不直接复制其中的文字、品牌标识、水印或具体业务数据。

### 9.1 结构与视觉语言

- 深色工作台布局：顶部工具栏、左侧主导航、右侧主内容区。
- 顶部保留全局搜索、通知和账户入口，强调应用级导航的稳定性。
- 主内容区采用“问候 / 页面标题 + 指标卡 + 图表 + 最近数据表”的信息层级，优先展示经营概览。
- 卡片使用低对比度深色表面、细边框和适度圆角，减少装饰性阴影，保持数据密集场景的清晰度。
- 图表、状态和进度使用少量高亮色，正文、表头和次要信息通过明度层级区分。
- 左侧导航需要有明确的当前选中态，并保证长列表、分组和底部设置入口可辨识。

### 9.2 主体颜色可调整

截图中的蓝黑色只作为参考，**不锁定为最终主体颜色**。后续设计应把背景、表面、边框、正文、主色和强调色做成可替换的主题 token，至少保留：

- 深色工作台作为默认参考方向；
- 主体色可按品牌方案调整，例如墨蓝、青绿或其他经过对比度验证的颜色；
- 主色变化不能降低正文、控件和图表的可读性；
- A02「通路」作为 Logo / 图标设计源保持独立，桌面主题色可以围绕它调整，但不能因此改变 A02 的主体图形和品牌配色。

### 9.3 当前状态

本节仅记录用户提出的桌面设计方向，暂不修改界面代码、功能入口、业务口径或平台资源。后续若进入实现，应由 Windows 与 macOS 分别按本平台方式接入，并使用同一套功能清单、交互目标和主题口径验收。
