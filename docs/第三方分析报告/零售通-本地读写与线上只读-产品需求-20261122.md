# 零售通 · 本地读写与线上只读 · 产品需求说明

> 版本：v0.1（需求稿）  
> 日期：2026-11-22（Asia/Shanghai）  
> 适用阶段：v0.1.x 原型 → v0.2 真实业务适配  
> 前置边界（已确认）：
> 1. **本地文件需要具体读写**，不是只做“读进来看看、浏览器下载一下”。
> 2. **线上数据只读，不写回平台**；不做自动改价、上架、发货、退款、发消息等业务写入。
> 3. **电脑故障、云同步、网盘备份属于用户自己的运维责任**；工具只负责本地数据可导出、可迁移、可读。

---

## 1. 目的

把“本地读写”和“线上只读”从一句原则，落成可开发、可验收的产品需求，避免三个常见跑偏：

- 把“本地读写”做成“只能读 + 浏览器下载”，用户拿不到指定路径的文件；
- 把“写回源文件”做成默认行为，误改客户原件；
- 把“线上只读”做成“顺手也能写”，越过用户授权，带来平台合规和账号风险。

本文件只定义**文件与数据连接层**，不改变现有业务口径；业务指标仍以答疑文档和后续确认结果为准。

---

## 2. 名词与边界

| 名词 | 定义 | 默认权限 |
| --- | --- | --- |
| 源文件 | 用户提供的原始工作簿，如仓库登记表、平台导出表 | 可读；默认不写；写回必须显式确认 |
| 生成文件 | 工具生成的看盘表、导出表、报告、日志包 | 可写；写到用户选择的位置；默认不覆盖同名文件 |
| 应用数据 | `本地数据/` 下的历史 JSON、`daily.sqlite3`、配置、映射 | 工具可读写；必须原子写、可导出、可迁移 |
| 导入归档 | 页面上传后保存到 `原始资料/导入记录/` 的副本 | 工具可写；按内容哈希去重；不改用户原件 |
| 线上数据 | 通过 URL/API/后台导出获得的销量、价格、库存等 | **只读**；不写回平台业务数据 |
| 凭证 | 登录态、Cookie、Token、API Key 等 | 只存系统钥匙串/安全存储；不写入配置、日志、导出 |

**责任边界：**

- 工具负责：本地文件读写可控、线上读取可用、失败可恢复、操作可审计、数据可迁移。
- 用户负责：电脑硬件/系统故障、云同步/网盘备份、平台账号权限与合规使用、备份策略。
- 工具不承诺：电脑级容灾、自动绕过验证码、无人值守自动登录、平台业务写入。

---

## 3. 总原则

1. **读写分离，不混为一谈。** “读源文件”和“写源文件”是两个动作，前者默认允许，后者默认关闭。
2. **默认保护原件。** 原始工作簿默认只读；不执行宏、不改公式、不静默另存。
3. **写操作必须显式。** 用户必须选择目标、看到写前预览、明确确认；不能因为“分析完成”就自动写盘。
4. **先预览，后写入。** 写文件前展示：目标路径、文件名、格式、覆盖/新建、影响范围、预计大小、差异摘要。
5. **原子写入。** 先写同目录临时文件，`fsync` 后原子替换；失败不留半截文件。
6. **可回滚。** 覆盖/写回前保留带时间戳和哈希的备份；提供“恢复上一版”。
7. **线上只读。** 连接器只实现读取类操作；任何业务写接口默认不存在，也不做“隐藏开关”。
8. **凭证最小化。** 只申请读取所需的最小权限；凭证不落普通配置、不进日志、不进导出。
9. **失败要能说人话。** 文件被占用、无权限、磁盘满、源文件已变化、登录态过期，都要给具体原因和下一步。
10. **所有操作可追溯。** 记录谁、什么时候、对哪个文件/数据源、做了什么、结果如何；不记录敏感内容。

## 4. 本地文件读写需求

### 4.1 文件分类与权限矩阵

| 文件类型 | 例子 | 读 | 写 | 默认行为 | 写前确认 | 版本/回滚 |
| --- | --- | --- | --- | --- | --- | --- |
| 源工作簿 | `样例.xlsx`、仓库盘点表、平台导出表 | 允许 | 仅显式开启 | 只读 | 必须 | 写前备份 + 可恢复 |
| 生成结果 | 看盘 Excel、CSV、日报、问题清单 | 允许 | 允许 | 新建，不覆盖 | 覆盖时确认 | 每次生成保留版本 |
| 导入归档 | `原始资料/导入记录/` | 允许 | 允许 | 自动去重保存 | 不需要 | 按哈希保留 |
| 应用数据 | 历史 JSON、`daily.sqlite3` | 允许 | 允许 | 原子写 | 破坏性操作确认 | 快照/回收站 |
| 配置/映射 | 字段映射、口径配置、外观偏好 | 允许 | 允许 | 本地保存 | 覆盖/删除确认 | 导出/导入 JSON |
| 日志 | 操作日志、错误日志 | 允许 | 追加 | 自动轮转 | 不需要 | 按保留策略 |

> 说明：`原始资料/` 下用户原件默认只读；`导入记录/` 是工具管理的副本，可按哈希去重写入。  
> 如果用户明确要求“直接改源文件”，按 4.3-B 的“写回源文件”流程执行，不沿用普通导出流程。

### 4.2 读取需求

**必须支持：**

- 用户通过系统文件选择器选择单个文件，或选择目录后扫描；
- 支持 `.xlsx`、`.xlsm`；`.xls` 给出明确提示“请先另存为 .xlsx”，不静默失败；
- 读取前校验：文件存在、扩展名、ZIP 结构、是否加密、是否超过大小限制、是否被 Excel 占用；
- 读取时计算 SHA-256；分析前再次校验，防止“读到一半文件被改”；
- 读取只读打开，不执行宏、不写回、不改变文件修改时间以外的内容；
- 目录扫描只列出 `.xlsx/.xlsm`，排除 `~$` 临时文件；不自动监控、不后台轮询（除非用户开启定时任务）；
- 读取失败时保留原文件，不生成“空结果”冒充成功。

**建议支持（v0.2）：**

- 多文件选择与合并规则；
- 明确“只读副本”与“可写副本”的区别；
- 文件路径含中文、空格、长路径、外接盘、iCloud/OneDrive 同步目录的兼容提示。

### 4.3 写入需求

#### A. 生成新文件（P0）

场景：导出看盘 Excel/CSV、日报、问题清单、备份包。

要求：

1. 用户选择目标目录和文件名；默认文件名带日期/版本，避免覆盖；
2. 目标已存在时，默认“另存为”，不静默覆盖；用户选择覆盖时，先备份旧文件；
3. 写入流程：临时文件 → 校验内容/大小 → `fsync` → 原子替换 → 重新读取校验；
4. 写入完成后显示：路径、大小、哈希、生成时间；提供“打开所在文件夹”；
5. 失败时保留临时文件或明确清理，不能留下半截可打开文件；
6. 生成文件不写入用户源文件，不修改源文件公式/格式/宏；
7. Excel 导出优先多 sheet + 格式 + 文本化编码；CSV 导出必须处理前导零、长 ID、公式注入。

#### B. 写回源文件（P1，默认关闭）

场景：用户明确要求把修正值、补充列、标记写回原工作簿。

要求：

1. **默认关闭**；必须在设置中单独开启“允许写回源文件”，并按文件再次确认；
2. 写前必须展示差异预览：哪些 sheet、哪些单元格、原值 → 新值、影响行数；
3. 写前校验：源文件哈希/修改时间与读取时一致；不一致则拒绝并提示重新导入；
4. 写前检查：文件是否被 Excel 打开（`~$` 锁文件）、是否只读、是否有密码/保护、磁盘空间是否足够；
5. 写前自动备份：同目录 `.backup/` 或用户指定目录，文件名含时间戳 + 原哈希；备份失败则禁止写入；
6. 写入采用“临时文件 + 原子替换”；`.xlsm` 必须提示宏/格式可能丢失，默认不写回，除非用户确认；
7. 写入后重新打开校验：sheet 数、关键单元格、哈希、文件可读性；失败则自动恢复备份；
8. 提供“恢复上一版”入口，保留至少最近 N 个版本（N 可配置，默认 3）；
9. 写入记录进入操作日志：文件、单元格范围、旧值哈希、新值哈希、操作人/时间、结果。

#### C. 应用数据与配置（P0）

- 历史 JSON、SQLite、映射配置、外观偏好属于工具数据，可直接写，但必须：
  - 原子写、失败不破坏旧数据；
  - 有 schema 版本；
  - 支持整体导出/导入；
  - 删除走回收站/软删除；
  - 配置不能只存 localStorage，必须可导出为 JSON 文件。

### 4.4 写入安全与一致性

| 检查项 | 要求 |
| --- | --- |
| 路径 | 只允许用户明确选择的目录/文件；拒绝 `..`、符号链接逃逸、系统目录、网络盘未授权路径 |
| 权限 | 写前检查目录可写、文件可写、磁盘剩余空间；失败给具体系统错误 |
| 并发 | 同一文件加锁；检测其他进程/Excel 占用；冲突时提示“文件正在使用” |
| 源文件变化 | 读取时记哈希 + mtime + size；写入前再次校验；变化则拒绝 |
| 原子性 | 临时文件与目标同目录；`fsync` 后 `os.replace`；失败清理 |
| 备份 | 覆盖/写回前必须备份；备份路径、哈希、时间写入日志 |
| 编码 | 路径/文件名 Unicode 正常；CSV 用 UTF-8 BOM；Excel 文本列显式设为文本 |
| 宏/格式 | `.xlsm` 写回前提示宏风险；不执行宏；不承诺保留所有复杂格式 |
| 回滚 | 一键恢复备份；恢复前校验备份哈希；恢复失败保留现场 |

### 4.5 交互流程

**生成文件：**

`选择导出 → 选择目录/文件名 → 预览内容与格式 → 确认 → 写临时文件 → 校验 → 原子替换 → 显示结果/打开文件夹`

**写回源文件：**

`开启允许写回 → 选择文件 → 分析/修正 → 查看差异预览 → 确认影响范围 → 自动备份 → 写临时文件 → 校验 → 原子替换 → 重新读取验证 → 成功/自动恢复`

**失败时：**

`显示具体原因 → 给出下一步（重试/另存/关闭 Excel/换目录/恢复备份）→ 保留原文件和备份 → 记录日志`

### 4.6 失败场景与处理

| 场景 | 处理 |
| --- | --- |
| 文件被 Excel 打开 | 检测 `~$` 锁文件/写入失败；提示“请关闭 Excel 后重试”；不强行写 |
| 磁盘空间不足 | 写前检查；不足则拒绝；临时文件清理 |
| 无写权限 | 提示具体目录/权限；建议另存到“下载/桌面” |
| 源文件已被修改 | 哈希/mtime 不一致；拒绝写回；提示重新导入 |
| 写入中途崩溃 | 临时文件残留可识别；目标文件保持旧版；重启后可恢复/清理 |
| 备份失败 | 禁止写回；提示备份目录不可用 |
| `.xlsm` 宏风险 | 默认不写回；用户确认后写，并提示宏可能丢失 |
| 目标同名 | 默认另存；覆盖需确认并备份 |

### 4.7 审计日志

每次读写记录一条 JSONL：

```json
{
  "time": "2026-11-22T10:30:00+08:00",
  "operation": "export|write_back|backup|restore|read",
  "source": "原始资料/样例.xlsx",
  "target": "导出/电商看盘表_2026-11.xlsx",
  "sha256_before": "...",
  "sha256_after": "...",
  "bytes": 123456,
  "result": "success|failed|rolled_back",
  "error": "",
  "user": "local"
}
```

日志不记录单元格内容、不记录凭证、不记录消费者个人信息；按天轮转，默认保留 90 天（可配置）。

## 5. 线上数据只读需求

### 5.1 “只读”的定义

**只读 = 不修改平台业务数据。**

- 允许：读取商品、销量、价格、库存、订单汇总、活动结果等；登录/刷新会话；分页/增量拉取。
- 禁止：改价、上架/下架、改库存、发券、报名活动、发货、退款、发消息、修改订单、写备注、调用任何 `POST/PUT/PATCH/DELETE` 业务接口。
- 登录/刷新 Token 属于“访问控制动作”，不算业务写入；但必须最小权限、单独授权、可撤销、可审计。
- 连接器不提供“写接口隐藏开关”；代码层面不实现业务写方法。

### 5.2 接入方式

| 方式 | 当前/后续 | 说明 |
| --- | --- | --- |
| 人工下载 | 当前已支持 | 用户自己登录平台导出文件，放入目录/拖入工具；完全本地处理 |
| URL 文件 | 后续 | 读取公开或带签名的数据文件；只读 |
| API/连接器 | 后续评估 | 只读 API；按平台文档申请权限；不支持业务写 |
| 浏览器登录态 | 后续评估 | 仅用于读取；不做自动绕过验证码/风控 |

### 5.3 连接配置

每个数据源独立配置：

- 名称、类型（URL/API/文件）、基础地址；
- 认证方式（Cookie/Token/API Key/系统钥匙串引用）；
- 权限范围（只读字段/接口）；
- 读取范围（地区、店铺、商品、日期）；
- 刷新频率（默认关闭/手动）；
- 超时、重试、退避、限速；
- 失败策略（重试/暂停/回退人工下载）；
- 启用/停用/删除。

### 5.4 凭证管理

- 凭证只存系统钥匙串/安全存储，不写入项目配置、不写入历史快照、不写入导出文件；
- 按数据源隔离，不能跨源复用；
- 显示“已配置/已过期/需重新授权”，不显示明文；
- 支持撤销/删除；删除后连接器立即失效；
- 日志只记录“认证失败/成功”，不记录 Cookie/Token。

### 5.5 频率与低负载

- 默认不轮询、不定时拉取；用户手动刷新或显式开启定时；
- 定时任务有最小间隔、随机抖动、失败退避；
- 无操作/休眠/锁屏时暂停；
- 拉取失败不无限重试；连续失败进入“暂停”并提示；
- 拉取结果先落临时区，校验后再入分析流程；不覆盖历史快照。

### 5.6 失败处理

| 场景 | 处理 |
| --- | --- |
| 登录态过期 | 提示重新授权；保留人工下载路径；不自动重登 |
| 验证码/风控 | 停止自动读取；提示人工处理；不绕过 |
| 403/429 | 退避、限速、暂停；提示权限/频率问题 |
| 网络失败 | 重试有限次；失败保留上次成功数据并标注时间 |
| 字段/结构变化 | 停止自动映射；提示格式变化，要求确认/人工映射 |
| 部分数据 | 标记“部分成功”；不把缺失当 0；给出缺失范围 |
| 重复数据 | 按源 ID/日期/商品去重；冲突提示 |
| 数据源停用 | 连接器停用；历史只读保留 |

### 5.7 合规与责任

- 只读取用户有权访问的数据；权限由用户申请和确认；
- 不绕过验证码、不破解登录、不使用未授权接口；
- 遵守平台协议；因账号/权限/抓取导致的封禁、处罚，由用户确认并承担；
- 数据最小化：只拉分析所需字段，不拉消费者个人信息；
- 本地保存、可删除、可导出；不默认上传云端；
- 线上数据与人工下载数据走同一套标准化/校验/分析流程。

### 5.8 线上只读验收

- 能配置一个只读数据源，测试连接成功；
- 只能执行读取；代码/接口中不存在业务写方法；
- 凭证不出现在配置、日志、导出、页面源码；
- 登录过期、429、网络失败、字段变化都有明确提示和降级路径；
- 关闭/删除数据源后，不再发起请求；
- 读取结果有来源、时间、范围、校验状态。

## 6. 统一操作模型

每个文件/数据操作都应有统一记录：

| 字段 | 说明 |
| --- | --- |
| `operation` | read / analyze / export / write_back / backup / restore / fetch |
| `source` | 本地路径或数据源 ID |
| `target` | 目标路径或输出 |
| `mode` | read_only / write |
| `confirmation` | 用户确认时间/方式（写操作必填） |
| `sha256_before/after` | 文件完整性 |
| `bytes` | 大小 |
| `result` | success / failed / rolled_back / partial |
| `error` | 可读错误码/信息 |
| `time` | 本地时区时间 |

状态机建议：

`发现 → 读取/拉取 → 校验 → 映射 → 分析 → 预览 → 确认 → 写入/导出 → 复验 → 完成/回滚`

任何一步失败，都不能跳到“完成”；历史快照与源文件状态要能对应。

## 7. 权限、安全、审计

1. **本地服务鉴权：** 生成一次性本地令牌，页面请求携带；防止同机其他页面/进程随意调用。
2. **路径白名单：** `/api/open`、`/api/directory` 只允许用户通过系统选择器选中的路径；不接受网页传入任意绝对路径。
3. **符号链接：** 解析真实路径，拒绝跳出允许根目录；拒绝系统目录、密钥目录。
4. **上传：** 限制大小/类型/展开体积；临时文件及时清理；不执行宏。
5. **写回：** 默认关闭；二次确认；备份；原子写；复验；可回滚。
6. **审计：** 本地 JSONL 日志；记录操作而非内容；可导出；可关闭但写操作默认开启。
7. **凭证：** 系统钥匙串；不落明文；不进日志/导出/快照。
8. **错误信息：** 不泄露绝对路径中的敏感目录、不泄露 Token/Cookie；给用户可操作的建议。

## 8. 验收清单

### 8.1 本地读取

- [ ] 选择 `.xlsx` / `.xlsm` 可读；`.xls` 有明确另存提示；
- [ ] 文件被 Excel 占用、加密、损坏、超大、路径含中文/空格，都有明确错误；
- [ ] 读取前后哈希一致；源文件内容不变；
- [ ] 目录扫描只列工作簿，排除 `~$`；
- [ ] 读取失败不生成空看盘结果。

### 8.2 生成文件

- [ ] 可选择目标目录/文件名；
- [ ] 同名默认另存，覆盖需确认并备份；
- [ ] 写入原子、失败不留半截文件；
- [ ] 导出后重新读取校验通过；
- [ ] CSV 前导零/长 ID/公式注入处理正确；
- [ ] 导出记录进入审计日志。

### 8.3 写回源文件

- [ ] 默认关闭；开启后仍需逐次确认；
- [ ] 写前差异预览准确；
- [ ] 源文件变化时拒绝写入；
- [ ] Excel 打开/只读/无权限/磁盘满时拒绝并提示；
- [ ] 备份成功才允许写；备份失败禁止写；
- [ ] 写入失败自动恢复备份；
- [ ] 可恢复上一版；
- [ ] `.xlsm` 有宏风险提示。

### 8.4 线上只读

- [ ] 只读连接器可配置、测试、拉取；
- [ ] 无业务写接口/方法；
- [ ] 凭证不落明文；
- [ ] 登录过期/429/网络失败/字段变化有降级；
- [ ] 关闭数据源后不再请求；
- [ ] 数据有来源、时间、范围、校验状态。

### 8.5 回归

- [ ] 历史快照、日记录、配置在读写后仍可打开；
- [ ] 本地数据可整体导出/导入；
- [ ] 升级版本后旧数据可读（schema 迁移）；
- [ ] 多实例/并发写不损坏数据；
- [ ] 日志可定位一次失败操作。

## 9. 非目标

- 不做平台自动改价、上架、改库存、发券、报名活动、发货、退款、发消息、写备注；
- 不做绕过验证码/风控的自动登录；
- 不承诺电脑级容灾、云同步、网盘备份；
- 不默认写回源文件；
- 不执行宏、不保证复杂 Excel 格式/图表/数据透视表无损写回；
- 不把线上数据默认上传云端。

## 12. 一句话

**本地读写要“可控、可预览、可回滚”；线上只读要“能读、可断、可审计”；电脑故障和云备份归用户，工具只保证数据可带走、可恢复、可解释。**
