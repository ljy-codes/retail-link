# 零售通 · 电商看盘

版本：0.1.1（探索版）

## 启动

在 Mac 上双击同目录的 **启动操控台.command**。启动后会打开本机浏览器，默认地址为 `http://127.0.0.1:8876`。端口被占用时会自动尝试后续端口，以终端显示的地址为准。

保持启动终端开启即可使用；在终端按 `Ctrl+C` 停止服务。

需要 Python 3.10 或更新版本与 openpyxl 3.1.5。启动脚本优先使用已有兼容环境；缺少依赖时会建立本工具专用 `.venv` 并安装依赖。首次安装依赖需要联网，之后分析在本机完成。

也可在本目录运行：

```sh
python3 -m pip install -r requirements.txt
python3 server.py --open
```

## 开始看盘

1. 点击选择 Excel，或把 `.xlsx`、`.xlsm` 文件拖入页面。也可点击“体验现有样例”。
2. 工具识别工作表并生成看盘结果。原始 Excel 不会被改写，宏不会被执行。
3. 查看商品经营、库存销量与数据问题。缺少数据时显示未计算状态，数据问题可追溯到工作表和单元格。
4. 在配置中调整统计日期、月计划口径、达成门槛、日均销量窗口、金额方式及工作表／列映射。可保存配置用于后续文件。
5. 打开商品详情，可手动修正计划、库存、供价或货损金额，再重新分析；手工修正与原数据分开，支持还原。
6. 可导出当前商品结果为 CSV；日常查看无需打开 Excel。
7. 在“历史记录”中查看之前保存的完整结果与配置。打开历史不会重新计算；原始文件仍可用时，可以在原配置基础上重新分析并生成新快照。

历史中的删除操作会把分析记录移入“已删除”，可随时恢复，不会删除原始 Excel。原件移动、删除或变更后，历史结果和问题仍可查看、导出；涉及原表预览与重新计算的操作需重新导入文件。

目录导入支持输入本机文件夹的完整路径、扫描、选择文件后分析。当前按用户操作读取；尚未实现目录自动监控和 URL 自动抓取。

## 可调整的默认口径

- 默认以报单金额衡量月计划，门槛为 85%。这源于现有样例公式，仍可切换口径。
- 默认保留源表金额，并提示与数量乘单价不一致之处；可切换为明细重算。
- 默认保留原始年份。样例销量为 2025 年，其他主要明细为 2026 年，因此严格日期下当期销量可能无法计算。只有主动开启年份对齐，才会按所选年份对齐，并保留提示。
- 库存与销量是否来自同一库存池需要显式确认；确认之前不输出可售天数。
- 在途与现货分开；超期在途保留并提示，未来日期数据不计入当期实际。
- 相比固定 Excel 模板，可调整工作表、表头行和列对应。支持常见横向日期表和按日期逐行记录的长表。复杂或未识别格式需先配置，工具不会凭空补齐数据。

## 外观与阅读

点击右上角“外观”，可即时调整：

- 显示模式：浅色、深色、跟随系统。跟随系统会响应系统主题变化。
- 工作台配色：定位蓝灰·青绿与经典紫，共两组；每组均支持浅色与深色。
- 阅读字号：标准、舒适、大号。

外观覆盖看盘表、历史、配置、商品详情、原始表预览和每日价格页面。偏好保存在当前浏览器，刷新后保留；“恢复默认”回到跟随系统、经典紫、标准字号。外观设置不会改动业务数据或分析口径。

## 每日价格与销量

点击左侧“每日价格与销量”。可以手工记录，也可以导入每天另存的价格 Excel：

1. 选择文件，核对工作表和表头行，指定商品、售价、当日销量、日期与店铺列。
2. 文件没有日期列时，明确这份价格表的业务日期。所选销量必须属于同一天；累计销量不能直接当作当日销量。
3. 预览记录、日期与问题，再确认保存。不同日的价格独立保留，不会被最新价格覆盖。
4. 重复记录默认跳过；可选择“补齐空白售价／销量”，适合价格与销量分表提供，已有数值冲突会要求核对。选择更新时保留旧版。
5. 可筛选日期／商品／店铺，查看每日价格和销量趋势，修改记录、查旧版本、删除及恢复。

售价、销量缺一项时保留空白。当前入口用于已发生的日记录，未来计划日期会提示并拒绝混入；一天多次变价的时段明细尚未实现。售价可能是标价，售价乘销量不等于实际成交额。

## 文件存放

- 原文件位于项目的 `原始资料/`；页面上传的文件按内容去重保存到其 `导入记录/` 子目录。
- 项目同级的 `本地数据/history/` 持久保存完整分析结果与当次配置；`本地数据/history_deleted/` 保存已删除、可恢复的快照。历史分页展示，不会自动清理旧记录。
- 运行数据独立于 `产品交付/`，更新工具版本不会覆盖历史；备份或迁移时应同时保留 `本地数据/` 和 `原始资料/`。可通过 `--data-dir` 指定其他数据目录。
- `本地数据/daily.sqlite3` 保存按日的售价、销量、来源及修订记录。
- 浏览器本地保存配置偏好；手工修正仅用于当前导入文件，不会自动套用到其他文件。
- 工具只监听本机 `127.0.0.1`。本版本无登录、云端同步或远程采集。

如果单独移动交付文件夹，工具仍可上传 Excel；“体验现有样例”需要同级项目中存在 `原始资料/样例.xlsx`。

## 当前范围

已围绕库存与销量计算、每日电商看盘建立首版。价格比例是经营表的基础指标；未实现完整利润核算、品牌返还自动判定、到货单自动核销、活动优化或采购下单。

开发进度与结论统一查看项目 `概览/task.md`；未确认业务问题查看`概览/答疑文档/2026-11-21.md`。
