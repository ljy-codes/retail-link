Windows 试用版 · v0.2.10

零售通使用说明

适用：Windows 10/11 x64。安装包内置运行环境，使用时不需要另装 Python，也不需要打开终端。业务数据在本机处理；当前试用包未做代码签名，Windows SmartScreen 可能要求先核对来源和 SHA-256。

本包为本地维护验收候选，由用户亲自安装验收；本次整理未执行安装。Mac 版需要在 Mac 上另行构建与复验。

产品用途

零售通把日常经营 Excel 中的商品、库存、销量、计划、发货、售后、货损与经营核对数据整理成一个本地工作空间。它帮助减少手工跨表查找，并把缺失、冲突和待人工确认的项目明确标出，不把未知数据自动当作 0。

安装

  1. 打开 零售通-v0.2.10-windows-x64-setup.exe，在安装页核对产品名称和版本。
  2. 默认安装到当前用户的应用目录，也可以点击“浏览…”选择其他可写目录；路径可以包含中文和空格。系统会在复制文件前检查目录、可写权限、占用状态和磁盘空间。
  3. 如果所选目录已有其他文件而不是零售通安装目录，安装器会直接拒绝并保留原目录，不会搬移、覆盖或删除已有文件。请选择空目录或尚不存在的目录。
  4. 按需要勾选“立即启动零售通”“创建桌面快捷方式”“创建开始菜单快捷方式”。三个选项都会按实际选择执行。
  5. 完成页会显示品牌、版本、实际安装目录、首次使用步骤、本地数据和联网说明，并可打开安装目录。安装器不再用简单弹窗代替完成流程。

覆盖安装时会沿用已登记的安装位置。旧版先进入可恢复暂存区，只有新版完整校验并落位后才清理旧版；失败时恢复旧版，不留下半安装。

首次启动

  1. 启动页依次显示“运行环境”“后端就绪”“页面加载”“可操作”四个阶段及耗时。正常启动完成后才允许操作页面。
  2. 如果超过启动保护时间、WebView2 缺失或本地服务退出，页面会显示原因，并提供“重新启动”“退出”和“显示启动诊断”。
  3. 菜单“应用 → 显示启动诊断”可打开本地启动日志、数据目录和错误日志位置。日志只保存在本机，不上传。

开始看盘

  1. 点击“导入数据”，选择或拖入 Excel；也可选择本机目录后勾选所需文件。
  2. 核对工作表用途、字段、仓库、单位与业务日期，不需要的表选择“忽略”。
  3. 点击“预览导入范围”。格式变化、日期、重复计划或商品标识冲突需要先处理或明确确认。
  4. 生成后查看商品看盘、数据问题与来源；缺失数据保持为空，不当作 0。
  5. 导出看盘表时选择目录和文件名，预览后保存。同名覆盖会保留备份，可恢复。

桌面-4 经营能力

  • 商品身份与分仓：按来源系统、商品 ID、规格和仓库关联；同名不同规格不会自动合并，分仓现货合计只作辅助。
  • 单品目标：每款商品独立判断是否达到目标，默认门槛 85%；超额商品不抵扣其他商品缺口。
  • 每日价格与销量：按日期、商品、店铺保留售价与销量，支持导入差异预览、修订、删除和恢复。
  • 净销量双视角：原销售归属与售后发生分别显示，不相加；缺失事件、单位或覆盖依据时保留“待核对”。
  • 货损双轨：登记值与公式盘差分别显示；盘差不自动认定为货损，人工确认差异须填写说明。
  • 受控源写回：默认仍生成新文件；开启后每次都必须选择原件、预览单元格和旧新值、勾选确认。写回前备份，写回后重读校验。
  • 数据覆盖报告：看盘首页汇总来源文件、观察日期、日期缺口、仓库范围、字段缺失、指标可用状态和下一步补资料动作。报告只读取已保存快照，不把缺失值当 0。

数据位置与安全

  • 应用数据默认位于 %LOCALAPPDATA%\零售通\。
  • 默认生成文件位于 %USERPROFILE%\Documents\零售通\生成文件\，也可选择其他目录。
  • 原始资料、导入副本、生成文件和写回备份属于不可替代内容，升级、普通卸载和彻底卸载均不会整体删除。
  • 本地服务只监听 127.0.0.1，不自动上传业务工作簿，也不定时抓取线上数据。主动点击外部链接时使用系统浏览器。

卸载

  1. 从 Windows“设置 → 应用 → 已安装的应用”选择零售通，或使用开始菜单中的卸载入口。
  2. 卸载程序从 HKCU 的实际 InstallLocation 解析路径，因此默认目录、自定义目录、中文路径和空格路径都可卸载。
  3. 明确选择“普通卸载”或“彻底卸载”，默认普通；彻底卸载会再次确认。确认页列出本次清理范围与保留范围。
  4. 完成后显示“卸载结果”：成功或部分失败、已删除内容、已保留内容、失败项、恢复位置和日志位置。失败时返回非零状态，不会把部分完成冒充成功。

普通卸载保留历史、设置、日志和用户数据。彻底卸载清理应用配置、历史、日记录库、导入格式模板、派生导入会话、日志和缓存，但始终保留《原始资料》、导入文件、生成文件、Documents 下用户文件、写回原件备份与恢复记录。卸载程序尽量移入回收站；无法进入回收站时会移动到可恢复暂存位置。

性能与诊断

启动日志记录进程启动、宿主窗口、后端就绪、页面载入、前端可操作和错误阶段。资源测试将统计应用主进程、内置 Python 与可归属的 WebView2 辅助进程，区分首次启动、冷启动、热启动、空闲和长时间静置。单看某一个进程的内存截图不能代表整体占用。

零售通 Windows v0.2.10 与 Mac v0.2.9 使用同一 desktop-4 功能基线。业务算法来自共享源码，Windows 只维护桌面容器、文件桥、进程管理、安装卸载和发布适配。本版为 x64 试用包，未提供 arm64 原生包。
