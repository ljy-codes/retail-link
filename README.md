# 零售通 Retail Link

零售通是一套本地运行的电商运营工具，当前从电商看盘开始：导入 Excel，识别库存、销量、报单、出库和在途数据，生成经营视图，定位数据问题，并保留历史结果。

## 当前能力

- `.xlsx`、`.xlsm` 导入与本机目录扫描
- 工作表、表头行和字段映射的人工调整
- 库存、销量、计划、出库、在途和货损看盘
- 数据异常定位到来源工作表和单元格
- 历史快照、软删除与恢复
- 每日售价与销量按日期、商品、店铺保存
- 浅色、深色、跟随系统，以及两组外观配色（默认定位蓝灰·青绿、经典紫）
- CSV 看盘导出

## 本地运行

需要 Python 3.10+ 和 `openpyxl`。

```bash
python3 -m pip install -r requirements.txt
python3 server.py --open
```

也可以双击 `启动操控台.command`。启动后打开本机页面 `http://127.0.0.1:8876`。

本仓库不包含客户原始业务表、运行历史和测试输出。上传文件只在本机处理；生产数据请放在仓库外部的数据目录。

## 长期工程推进原则

每日疑问服务于当前阶段目标：每份日期答疑最多保留 5 项，按影响范围和阻塞程度排序。低优先级问题先记录，不阻塞主线；可以用透明默认值、可配置规则和可撤销操作继续验证的，不等待全部口径确认。每个阶段设置目标、验收条件和时间盒。


## v0.1.2 本地文件与迁移

- 预览后把五工作表 Excel 保存到所选本机现有目录；保留 CSV 与 Excel 下载。
- 同名覆盖需确认，写前校验备份，临时文件与最终文件均重新读取校验；失败恢复旧文件。
- 本地数据与记录入口可看 JSONL 日志、恢复生成文件版本、导出和导入迁移 ZIP。
- 迁移包含历史、日记录及旧版、配置、字段映射与外观；SQLite 使用 backup API，ZIP 校验清单与哈希。
- 源 Excel、生成文件和本机文件恢复指令不随数据迁移包传递；原工作簿保持只读。
- 当前目录选择为完整路径输入。未提供原生安装包、源文件写回及成功迁移的一键撤销。

运行纯虚构文件的新增单元测试：

```bash
python3 -m unittest discover -s tests -v
```
