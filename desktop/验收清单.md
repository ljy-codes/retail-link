# 配对桌面版本验收

Mac v0.1.9 / Windows v0.1.10；功能基线 desktop-3。Mac 先通过，Windows 跟随实现；操作系统对话框外观可不同，功能和计算输出必须一致。

| 场景 | 必须验证 |
| --- | --- |
| 安装启动 | 内置环境、无终端、中文／空格路径、只读资源、可视启动、错误与重试 |
| 生命周期 | 单实例、端口冲突、退出回收子进程、空闲无新增轮询 |
| 文件输入 | 系统多文件选择、拖拽、目录选择、取消不改值、逐表范围确认 |
| 核心业务 | 库存／销量／计划／出库／货损，缺失与0、单位、日期、重复与编码冲突 |
| 每日记录 | 新增、Excel导入、补空／替换、旧版、趋势、删除与恢复 |
| 原始价量与商品关联 | 双层日期、合并仓位、年份保留、0/空、原始来源、订货表关联、规格/地区冲突与别名持久保存 |
| 导入变更核对 | 新增/未变/冲突/补齐预览、旧新差异、策略与映射变化失效、显式更新保留旧版、重复不累计 |
| 日记录导出 | 当前筛选全部匹配记录跨页导出Excel/CSV，范围与销量口径明确、文字ID、原生保存重读一致 |
| 历史与导出 | 打开／重算边界、删除／恢复、Excel本机保存、同名备份和恢复、Excel／CSV下载 |
| 设置与迁移 | 模板、分析配置、日记录映射、主题跨端口与重启保留、ZIP导入导出及日志 |
| 原生下载 | XLSX／CSV Blob／ZIP选择路径，不自动覆盖已有文件 |
| 数据保护 | 应用升级不清历史，源文件／生成文件不随卸载删除 |
| 卸载 | 普通／彻底分类，确认、范围、可恢复；真实用户资料不用于破坏性测试 |
| 平台一致 | 配对版本功能清单相同、核心资源SHA一致，同一虚构样本逐项输出一致 |

每轮在测试空间记录真实通过、失败、未执行与环境限制，不能用静态代码检查替代系统原生操作测试。

## 当前规则与实现状态（2026-11-24）

11月22日答疑已全部收齐。desktop-3已完成单品85%独立考核、总览逐款正差额合计、业务状态筛选与每日任务；缺失、零计划、月底到期和旧快照口径均有覆盖。净销量重建、货损双轨、源写回开关仍待实现，不列入本轮已交付。

Mac 0.1.9 新增原始价量表展开、持久商品关联、导入差异预览及筛选日记录导出。组合历史恢复后的所有原件及硬链接受普通导出保护，预览与提交均复查。Windows 0.1.10 复用同一业务代码，使用 WinForms + WebView2、内置 Python、用户级安装和原生文件桥。

现有真实价量样表有13个日期组，但169个价量组合均空，只验证结构；数值完整流程使用隔离虚构数据。不得将技术测试算作真实业务对账完成。

Windows 最终验收在本机 Windows 10.0.26300 x64 完成：安装包构建与冒烟、GUI 实际渲染、首页无样例提示、4xx 中文错误、单实例、原生保存重读、偏好重启保留、正常退出后端回收、覆盖升级、普通卸载和彻底卸载。卸载脚本已用 Windows PowerShell 5.1 实际解析，普通与彻底卸载退出码均为 0；用户原始资料、导入文件、生成文件与 Documents 文件在卸载后保留。本轮 Python 回归 171 项通过、2 项环境跳过，Windows 包契约 8 项通过，Node 界面脚本 39/39 通过；最终安装包 SHA-256 记录于 `docs/平台发布记录.md` 和 Release notes。

自动化测试不能替代全部真实业务 Excel 对账；本轮使用虚构工作簿完成技术验收，不使用生产业务资料。Windows 包仅覆盖 x64，未代码签名，依赖 WebView2 Runtime。平台发布与共享代码按 `docs/GitHub分支与版本规定.md` 执行。

## 单品考核关键案例

- A计划100、完成200，B计划100、完成0：合计达成100%，A达标、B未达，缺口合计85，不能为0。
- 恰好85%计达标；有实际缺口时不能被浮点相对误差吞掉，包括大额计划差一分钱。
- 缺计划、缺完成和非正计划为待核对；已知缺口保留，完整任务不能冒充0。
- 截止日后剩余自然日均摊任务；月末仍未达标显示已到期，已达标任务真实0。
- 人工修正后重新分析生成新状态；旧快照保留历史数值和口径，新旧导出明确区分。
